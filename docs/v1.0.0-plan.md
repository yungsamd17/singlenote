# v1.0.0 Plan — Singlenote

Checklist for the first stable release from `v0.2.6` (`versionCode 8`). Keep the “one active note” core, make it shippable.

---

## Features

- [ ] **Export / Import** — Settings → Export/Import via Storage Access Framework. Saves active + archived notes + prefs as JSON/txt; validates on import.
- [ ] **Archive search** — Filter archived notes by text (debounced, case-insensitive).
- [ ] **Swipe actions in Archive** — Swipe to archive/delete with haptics + Snackbar undo.
- [ ] **Dynamic Color** — Material You toggle (Android 12+), fallback to current Light/Dark/System.
- [ ] **Widget preview & sizes** — Light/dark preview in picker, adapts to small/medium sizes.
- [ ] **Notification actions** — Pinned notification adds Copy + Archive buttons.
- [ ] **Open-source licenses screen** — Settings → About lists licenses.

## Improvements

- [ ] **Editor undo** — Snackbar Undo (5 s) after Archive/Clear, survives rotation.
- [ ] **Widget reliability** — Update within 5 s of `ACTION_NOTE_UPDATED`, deduped receiver, respects WorkManager budget.
- [ ] **Tile polish** — Subtitle truncated to 40 chars, locale-aware, no crash on null `qsTile`.
- [ ] **Empty states** — Unified blank-note handling across editor/widget/tile/notification.
- [ ] **Edge-to-edge & rotation** — Respects `WindowInsets`, no jank after rotate, keyboard stays open while typing.
- [ ] **README / store copy** — Screenshots, feature graphic, Play/F-Droid descriptions.

## Fixes

- [ ] **Signing** — Replace debug keystore for `release` builds with proper upload keystore (`KEYSTORE_*` secrets). Required for Play.
- [ ] **Room migrations** — Add auto-migration tests, disable destructive fallback, enforce single active-note invariant.
- [ ] **Accessibility** — TalkBack correct on Note/Archive/Settings, 48 dp touch targets, all icons have `contentDescription`.
- [ ] **AGENTS.md drift** — Update overflow-menu docs (now has trailing icons, 28 dp shape) and any stale conventions.

## Build / Release

- [ ] **Version bump** — `versionCode 10`, `versionName "1.0.0"` in `app/build.gradle.kts`.
- [ ] **Dependencies** — Bump `kotlin`, `agp`, `composeBom`, `room`, `glance` to latest stable before freeze.
- [ ] **CI** — Ensure `lintRelease` clean, Gradle caching kept, hash of `app-release.apk` logged.
- [ ] **Tag release** — `git tag v1.0.0 && git push origin v1.0.0` → workflow publishes `app-debug.apk` + `app-release.apk` to GitHub Release.

## Quality

- [ ] **Tests** — Unit coverage ≥ 70% (`NoteViewModel`, `ArchiveViewModel`, `NoteRepository`, `PinNotification`), 1 instrumented archive-flow test.
- [ ] **Manual QA** — Pass on Android 10 + 15: type → background → foreground persists, archive → undo works, export → clear → import restores, theme toggle survives restart.
- [ ] **Performance** — Cold start < 700 ms mid-range, no StrictMode violations, no `SecurityException` on notify.

## Out of scope for 1.0.0

Multi-note, tags/folders, markdown/checklists, images/voice, sync/cloud, biometric lock, analytics, widget config activity.
